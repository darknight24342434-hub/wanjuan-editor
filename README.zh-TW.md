# 萬卷文庫

萬卷文庫是以文件為中心的本機 AI 文書工作台。前台分成「新聞審稿」與「寫作助手」兩個入口，卡庫複雜度留在系統內部。

## 現階段能力

- 從百鬼文庫 `INDEX.yaml` 唯讀載入 282 張正式卡、32 份模板與 11 張人物卡。
- 將 13 張新制 `original_language_20plus_close_read_complete` 獨立標為「完整文本書目大師卡」。
- 其餘 125 張文學大師卡另列，不把舊制 20 作品包、10+、部分文本或譯本卡混稱完整。
- 不載入 `_draft_missing_qcpass_20260617` 隔離草稿。
- 顯示卡片正本 frontmatter 狀態與資格標籤。
- 建立、編輯、儲存與重新開啟文件。
- 每次有效儲存建立新版本；原稿雜湊永不改寫。
- 比較任意歷史版本與目前版本。
- 還原舊版本時建立新版本，不刪除歷史。
- 執行本機規則審稿，檢查高風險套語、連續標點、格式與過長段落。
- 保存本次卡片、模板、人物、輸入雜湊與審稿結果。
- 新聞審稿可上傳 TXT、MD、DOCX，或直接貼入中央編輯器。
- 新聞模式固定呈現新聞編輯、百鬼總編質疑、百鬼總編成品審與人類核准流程，並依本機預檢建議改寫人物卡。
- 來源線索可逐項標成已確認、存疑或來源缺口；無來源稿不能用假線索解鎖流程。
- 新聞編輯卡與百鬼總編卡可建立獨立、可追溯的保守修訂版本，並立即顯示前後差異。
- 人工核准綁定目前修訂版本、目前審稿紀錄與完整來源裁定快照；任一項變更即自動失效。
- 只有來源已處理、人物卡已修訂、修訂版已重審且人工核准後，才可建立「影音企劃草稿」；草稿不會自動派工。
- 影音企劃包含影音價值問題、採訪與攝影任務、30／60／90 秒及 YouTube 長版骨架、風險缺口與下一步。
- 新聞稿只保留單一輸入入口；來源線索由附件檔名、內文網址、記者／來源／採訪等署名行自動擷取，無法辨識時由審稿結果列為待補缺口，不要求使用者另填來源欄。
- 來源裁定、人物卡改寫、核准與影音企劃都比對前端看到的版本；舊分頁操作會回覆 409，不會套到新稿。
- 寫作助手先讀概念，再推薦最多 5 張大師卡，以白話說明內容取向、推薦理由、適用情境、不適用情境與卡片資格。

## 重要邊界

- 現在只有 `local_rules` 本機規則引擎，尚未連接外部模型。
- 新聞模式目前完成本機預檢與保守格式修訂；來源語義質疑、可讀性、有趣性與深度仍標示為等待語義模型。
- 選擇大師卡與人物卡會建立可追溯配置，但目前不會假裝已執行完整 AI 人格審稿。
- 中時新聞工作流已納入「新聞編輯卡 → 百鬼總編卡（質疑審＋成品審）」的卡片配置；目前執行引擎仍只有本機規則預檢，尚未連接完整語義模型。
- 人類可以在語義總編尚未接入時越權定稿，但介面與影音風險清單會明示「百鬼語義待補」，不可冒充百鬼總編通過。
- 影音企劃目前只產生可追溯的結構化骨架，固定標示「企劃草稿・不可派工」；不得視為正式採攝任務。
- 預設只綁定 `127.0.0.1`；要綁其他位址必須先在 `data/access.json` 把 `allow_external` 設為 `true` 並設定密碼，否則啟動即報錯。
- 本機 HTTP 服務會拒絕非本機 Host、跨站寫入與非 JSON 寫入；這仍不等於外網安全。
- **沒有 HTTPS**：對外開放時全程 HTTP 明文，密碼與稿件內容在網路上可被同網段側錄或竄改。只可用在區網或 Tailscale 等受信任網路，絕不可直接掛到公網或連接埠轉發到 Internet。
- 密碼是單一共用密碼，沒有帳號、沒有多因素、沒有稽核；session 只存在記憶體，伺服器重啟即全部失效。
- 登入通過後就是完整權限，包含改稿、核准與建立影音企劃草稿。

## 啟動

```powershell
Set-Location -LiteralPath '<你 clone 這個 repo 的位置>'
python -m pip install -r requirements.txt
.\啟動.ps1
```

瀏覽器入口：`http://127.0.0.1:8765`

### 開放外部連線（區網／Tailscale）

先確認 `data/access.json`：

```json
{ "password": "你的密碼", "allow_external": true }
```

再以對外位址啟動：

```powershell
python app.py --host 0.0.0.0 --port 8765
```

其他機器連 `http://<本機IP>:8765` 會被導向 `/login`，輸入密碼後取得 12 小時有效的 session；本機 `127.0.0.1` 來源維持免登入。開放前請先讀「重要邊界」的 HTTP 明文風險。

## 測試

```powershell
python -m compileall src tests
python -m unittest discover -s tests
```

## 主要路徑

- `app.py`：啟動入口。
- `src/catalog.py`：百鬼文庫唯讀轉接器。
- `src/repository.py`：文件、版本與審稿紀錄。
- `src/review.py`：本機規則審稿。
- `src/server.py`：本機 HTTP API 與靜態網站。
- `static/`：三欄文檔工作台介面。
- `data/studio.db`：本機 SQLite 資料庫，首次啟動時建立。
- `data/access.json`：外部連線開關與登入密碼；不存在或 `allow_external` 為 false 時只綁本機。
- `tests/`：卡庫、原稿不可變與審稿規則測試。

## 資料正本

- 百鬼卡庫：環境變數 `WENKU_BAIGUI_ROOT`（未隨 repo 發布）
- 中時研究：環境變數 `WENKU_CHINATIMES_ROOT`（未隨 repo 發布）
